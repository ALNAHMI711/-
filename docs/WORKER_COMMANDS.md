# أوامر العامل (Worker Commands)

هذه الطبقة تحدد عقداً آمناً بين الـ Control Plane والعامل السحابي.

- `EXECUTE_JOB` لتشغيل مهمة محددة.
- `CANCEL_JOB` لإلغاء مهمة.
- `DRAIN` لإيقاف استقبال مهام جديدة قبل الصيانة.
- كل أمر مرتبط بعامل محدد وله وقت إصدار وانتهاء.
- الأوامر قابلة للتكرار بأمان عبر `command_id` (idempotency).
- لا تحتوي الأوامر على كلمات مرور أو مفاتيح API أو OAuth tokens.
- التنفيذ الشبكي الفعلي، المصادقة، والتخزين الدائم ستكون ضمن adapters إنتاجية لاحقة.
- العامل يتصل بالـ Control Plane اتصالاً صادراً وآمناً؛ لا حاجة لفتح Docker أو SSH للواجهة العامة.
